# v5-20240915 数据结构


> (20240915) 注意: 仍在设计中，目前版本依然使用v4

1. 字段变更：
   - ``toiletType`` -> ``type``
   - ``gpsCoord`` -> ``loc``
     - ``type`` -> ``coordinateSystem``
   - ``timestamp`` -> ``lastUpdateAt``
   - ``type`` -> ``types``
     - 原先数字改为字符型标识，明确语义
     - 移除 ``bi`` （二元性别）：绝大部分厕所都有，因此没必要包含此字段
       - 新增 ``maleOnly``、``femaleOnly`` :代表仅限某一特定性别
   - ``toiletMetadata`` -> ``properties``
     - 内部属性修改，明确语义:
       - ``isPrivate`` -> ``isPrivateArea``
       - 移动``accessible`` 字段属性到根下的``extra``字段中
     - ``extra`` -> ``facilities`` 
     - 合并``score`` 字段到``comments``中
       - ``recommendation`` -> ``rating``
       - 此字段可以考虑保留更多数据
   - ``extra``
     - ``accessible``
       - 移除 ``isInBinary``: 二元卫生间内是否包含无障碍设施属性用``properties.facilities.hasAccessibilityFeatures``表达
       - 新增 ``comments`` 字段: 备注无障碍卫生间的相关信息，例如管理员的联系方式等
     - 新增 ``identifiers``: 用于标识可能拥有的额外信息供识别（比如爬虫扒的，原生不支持（通过插件支持））
       - todo 可能还要改
   - ``time``
     - 移除 ``unknown``字段：可以从开放时间属性推断
     - ``allDay`` -> ``isAllDay``
     - ``startTime`` -> ``openAt``
     - ``endTime`` -> ``closeAt``
   - ``comments``
     - 修改为``array``形式
     - 增加签名验证
   - ``img`` -> ``images``
